# 프로필 유지보수 안내

이 저장소의 `README.md`는 `chunwoolee-dev` GitHub 프로필에 표시됩니다.

## 파일 구성

| 파일 | 역할 |
| :--- | :--- |
| `README.md` | 소개, 관심 분야, 기술과 경험을 설명합니다. |
| `profile-banner.svg` | README 상단 배너를 표시합니다. |

## 수정 시 확인할 사항

- 소개와 기술 목록은 실제 경험을 기준으로 작성합니다.
- 배너 문구를 바꾸면 SVG의 `title`·`desc`와 README 이미지의 `alt`도 함께 확인합니다.
- README에서 배너 경로 `./profile-banner.svg`가 유지되는지 확인합니다.
- 기술 배지 이미지의 `alt`에는 해당 기술 이름을 기재합니다.
- 공개 저장소에 연락처, 인증 정보, 비공개 프로젝트 자료를 추가할 때는 공개 범위를 먼저 확인합니다.
- 병합 후 [프로필](https://github.com/chunwoolee-dev)에서 이미지와 표가 정상적으로 표시되는지 확인합니다.

## Achievements 표시

Achievements는 GitHub가 활동에 따라 자동으로 부여합니다. 이 문서나 README에 이미지를 추가하는 것만으로 획득되지는 않습니다.

획득한 배지는 계정 설정의 `Show Achievements on my profile`에서 표시 여부를 관리할 수 있습니다.

관련 안내: [GitHub 프로필 참고 문서](https://docs.github.com/en/account-and-profile/reference/profile-reference), [기여와 Achievements 공개 범위 설정](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/manage-visibility-settings-for-private-contributions-and-achievements).
